## 2. עדכון התכנית

פשוט עורכים את התאים בלשונית **`תכנית סופית`**. אין צורך לעשות שום דבר אחר.

- השינוי מופיע באתר תוך **עד 5 דקות** (יש זיכרון זמני). חבר שרוצה לראות מיד – מרענן את הדף.
- **לא לשנות את שמות העמודות** בשורת הכותרת (`שבוע`, `ריצה 1 - קלה`, `ריצה 2 - איכות`, `ריצות 3-4 - קלות / התאוששות`, `ריצה 5 - ארוכה`, `שבוע מתחיל` וכו׳). האתר מוצא את העמודות לפי השם.
- **`שבוע מתחיל`** חייב להיות יום שני (תאריך). ממנו מחושבים התאריכים של כל ריצה.
- העמודות הפרטיות שלי (`ק״מ בפועל`, `בוצעו ריצות`, `RPE שבועי`, `כאב`, `סטטוס`, `הערות / התאמות`, `סיכום לוואטסאפ`) **לא נשלחות לחברים**. הן מופיעות רק במסך המאמן.

### איך לכתוב אימון בתא
שתי הצורות עובדות:

```
חימום: 3 ק״מ
סט מרכזי: 6*800 3:50-4:00, 2:00 דק׳ קל
שחרור: 1 ק״מ
סה״כ: 9 ק״מ
```

```
3 ק"מ חימום
6* 800 3:50-4:00, 2:00 דק׳ קל
1 ק"מ שחרור
```

טיפים:
- **יום מיוחד:** כותבים את היום בתחילת התא, למשל `שבת: 22 ק״מ קל` – והריצה תשובץ בשבת במקום ביום הרגיל.
- **שתי ריצות בתא של ריצות 3-4:** `ריצה 3: 10 ק״מ קל ריצה 4: 6 ק״מ התאוששות`.
- **בוקר וערב:** `(בוקר) 12 ק״מ קל + (ערב) 6 ק״מ קל` – מוצג כריצה אחת בשני חלקים.
- **הערה בסוגריים** כמו `(אם הטסט תומך: 4:20)` מוצגת כהערה קטנה מתחת לשלב.
- אם האתר לא הבין תא – הוא מציג את כל הטקסט כמו שהוא. שום דבר לא הולך לאיבוד.

### סוגי ריצה וצבעים
ירוק = קלה / התאוששות · כתום = איכות · סגול = ארוכה · צהוב = טסט / תחרות.
הסוג נקבע לפי העמודה. מילים בתא משנות אותו: "טסט", "מרוץ" / "מירוץ" או "מרתון תל אביב" → טסט / תחרות; "כוח", "אליפטי" → אימון משלים (בצבע של קלה).

## 5. הלשוניות `Log` ו-`Schedule`

האפליקציה **מוסיפה** אליהן שורות ולא עורכת אותן.

- **`Log`** – כל "סימון ביצוע". אם חבר סימן כמה פעמים את אותה ריצה, **השורה האחרונה קובעת**.
- **`Schedule`** – כל הזזת יום. שורה עם יום ריק = "החזר לשיבוץ המקורי".
- מותר **למחוק** שורה שגויה (למשל בדיקה). לא כדאי לערוך שורות קיימות ביד.

## 8. עדכון ה-Apps Script

נדרש **רק** כשמשנים את `Code.gs` (לא כשמשנים את התכנית).

1. בשיט: **Extensions → Apps Script**.
2. `Cmd+A`, מדביקים את הקוד החדש, `Cmd+S`.
3. אם השתנו הרשאות: בוחרים **setup** ← **Run** ← מאשרים (Review permissions ← החשבון ← Advanced ← Go to… ← Allow). ההרשאה צריכה להיות רק ל**גיליון הזה** (`@OnlyCurrentDoc`).
4. **הכי חשוב:** **Deploy → Manage deployments** ← העיפרון ✏️ ← **Version: New version** ← **Deploy**.
   בלי זה האתר ממשיך לעבוד מול הגרסה הישנה. הכתובת נשארת אותה כתובת.

הגדרות פריסה (אם פעם צריך ליצור מחדש): **Web app**, Execute as: **Me**, Who has access: **Anyone**. אם יוצרים פריסה *חדשה* (ולא New version), הכתובת משתנה – וצריך לעדכן אותה ב-`config.js` באתר.

`setup()` בטוח להרצה חוזרת – הוא לא דורס לשוניות קיימות.

## 10. אבטחה ופרטיות

- האתר והמאגר ציבוריים. אין בהם סיסמאות או נתונים אישיים.
- מי שיודע את כתובת ה-API יכול לקרוא את התכנית והיומן, ולהוסיף שורות ל-`Log` ול-`Schedule`. הוא **לא** יכול לשנות את התכנית, למחוק שורות, או לגשת לקבצים אחרים.
- ה-Apps Script מוגבל לשיט הזה בלבד (`@OnlyCurrentDoc`).
- **קוד קבוצתי (אופציונלי):** ב-Apps Script ← ⚙️ Project Settings ← Script Properties ← `PIN` עם ערך, ובאתר ב-`config.js` מוסיפים `PIN: 'אותו ערך'`. אז רק מי שבאתר יוכל לשמור. (זה עוצר משתמשים מזדמנים, לא מישהו נחוש.)
- **ביטול הגישה של Claude ל-GitHub:** ב-GitHub ← Settings ← Applications ← Authorized OAuth Apps ← GitHub CLI ← Revoke.
